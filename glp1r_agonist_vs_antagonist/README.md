# Связывание агонистов и антагонистов GLP-1R и учёт при дизайне

Литобзор к Challenge 3 (GLP1R) конкурса Anthropic × Adaptyv. Дата сборки: 2026-10-20.

- `REPORT.md` — отчёт (резюме, контекст задачи, структурная модель, агонисты, антагонисты, сводная таблица, смещённый агонизм, выводы для дизайна, прецеденты, ограничения, литература)
- `GLP1R_agonist_vs_antagonist.xlsx` — таблица (12 листов: README, сравнение, лиганды, SAR пептида по позициям, остатки рецептора (общие и агонист-специфичные), реестр 80 структур PDB, чек-лист дизайна, 4 листа расчётов, источники)
- `*.csv` — те же листы в CSV (UTF-8 с BOM)
- `figures/` — два графика по собственным расчётам (fig1, fig2) и семь аннотированных 3D-сцен (figA–figG; figG — положение хотспота Baker Leu123 на борозде ECD): ключевые остатки рецептора подписаны прямо на структурах 6X18, 6LN2, 3C5T, 5E94, 5VEW, 6X1A, 6ORV, 6XOX
- `structures/6X18_GLP1R_hotspots.pdb` — 6X18 (рецептор + GLP-1, без G-белка) с классом остатка в колонке B-фактора (10 борозда ECD, 20 общие TMD, 30 агонист-специфичные TMD, 40 структурные контакты; пептид: 50 — 7–17, 60 — 18–23, 70 — 24–36); раскраска в PyMOL: `spectrum b`
- `structures/show_hotspots.pml`, `structures/6X18_GLP1R_hotspots.pse` — скрипт и готовая сессия PyMOL: остатки раскрашены по классам (синий — борозда ECD, зелёный — общие TMD, розовый — агонист-специфичные TMD, серый — структурные контакты; оранжевый — N-модуль пептида), с подписями остатков; `pymol show_hotspots.pml` из папки `structures/`
- `scripts/` — скрипты расчётов

Версия отчёта в Claude Docs: https://claude.ai/artifact/3DE6iaK2HfZ9Pfbe6fvoJW

Числа из статей — со ссылкой на источник; числа «расчёт» посчитаны автором на структурах RCSB (см. `scripts/README.md`).
